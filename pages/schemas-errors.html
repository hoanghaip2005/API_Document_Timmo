Common rules

Topic Rule
Currency Backend currency EUR; frontend có thể render ký hiệu đ.
Roles Private app dùng owner|employee; admin chỉ platform.
Money Money là number theo money scale backend.

Input validation boundaries

Backend validate body bằng Zod schema trong src/business/*/*-shared.ts. Phần lớn text được trim trước khi đo độ dài. Password dùng chung passwordPolicySchema: 8..50 ký tự, chỉ kiểm tra độ dài, không bắt buộc chữ hoa/số/ký tự đặc biệt.

Group Boundary
Auth/register/reset email phải đúng định dạng nhưng chưa chặn max length; name 2..100; password 8..50; otp đúng 6 chữ số. Signin không nhận username/password trong body, chỉ dùng Firebase ID token trong header.
Account/profile PATCH body phải có ít nhất 1 field. name/displayName 1..100; phone max 30; address max 255; avatarUrl phải là URL hợp lệ hoặc chuỗi rỗng. Avatar upload: fileName 1..255, contentType bắt đầu bằng image/, file decode tối đa 5MB.
Employee name 2..100; password 8..50 khi tạo hoặc đổi; branchId không rỗng; role chỉ nhận employee; phone max 20; money field phải đúng scale tối đa 2 chữ số thập phân.
Branch/service Branch name 1..100, code max 30, settlementCutoffTime dạng HH:mm. Service amount/price có thể là string hoặc number nhưng phải parse được money scale backend.

Rate limits

Group Limit Applies to
All API 180/min by IP /api/*
Signin/register owner 8/min by IP and 8/min by email /auth/signin, /admin/signin, register owner
OTP request 10/10min by IP and 3/10min by email /auth/forgot-password/request-otp
OTP verify/reset 20/10min by IP and 6/10min by email verify OTP, reset password
Session/token 15/min logout, change password, refresh token
Read/write/upload Read 90/min, heavy read 24/min, write 24/min, upload 6/10min Profile, branch, service, employee, attendance, report, avatar

Khi bị chặn backend trả 429 kèm Retry-After, X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Window-Ms và body type=/request/rate-limit.

Standard error

error.json 
{
  "type": "/employee/invalid-request",
  "message": "Invalid request"
}
Status Meaning Client action
400 Invalid request Sửa body/query.
401 Unauthenticated Refresh token hoặc sign-in lại.
403 Forbidden scope/role Không retry nguyên trạng.
409 Business conflict Refresh màn và hiển thị lý do.
429 Rate limited Chờ Retry-After.

Settlement V2 money rule

  1. ownerBaseDiscount = totalDiscount * ownerDiscountCoverageRate / 100
  2. employeePool = totalDiscount - ownerBaseDiscount
  3. Chia employeePool theo employee.totalRevenue / totalRevenue toàn ngày.
  4. Commission: ghi discountAllocated, trừ employeeEarning.
  5. Hourly/fixed: ghi ownerDiscountSupported, cộng vào chủ chịu.
  6. totalOwnerDiscount = ownerBaseDiscount + sum(ownerDiscountSupported).
