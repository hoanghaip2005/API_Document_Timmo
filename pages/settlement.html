GET/api/v1/employee/session/settlements

List ngày chốt sổ theo branch/range.

Auth: Backend access tokenScope: owner + branch accessUsed by: /daily-settlement list

Headers

Field Type Required Rule Example
Authorization string Yes Bearer accessToken sau signin/refresh-token. Bearer eyJ...
X-Firebase-AppCheck string Prod Firebase App Check token. Monitoring không cần. eyJ...

Query params

Field Type Required Rule Example
branchId/storeId string Yes Branch id. branch_123
fromWorkDate date Yes YYYY-MM-DD. 2026-06-01
toWorkDate date Yes YYYY-MM-DD, range <= 31 ngày. 2026-06-30

Request body

GET không có body.

cURL

curl 
curl -X GET "$API_BASE/employee/session/settlements?branchId=branch_123&fromWorkDate=2026-06-01&toWorkDate=2026-06-30" \
  -H "Authorization: Bearer eyJ..." \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN"

Successful response

200 response 
{
  "branchId": "branch_123",
  "storeId": "branch_123",
  "fromWorkDate": "2026-06-01",
  "toWorkDate": "2026-06-30",
  "rangeDayCount": 30,
  "items": [
    {
      "workDate": "2026-06-06",
      "status": "ready",
      "attendance": {
        "totalCount": 2,
        "openCount": 0,
        "closedCount": 2,
        "incompleteCount": 0
      },
      "totalRevenue": 105,
      "totalDiscount": 5,
      "totalNetAmount": 100,
      "totalOwnerNetAfterDiscount": 65
    }
  ]
}

Response fields

Field Type Meaning
items[].status open|ready|closed Trạng thái ngày.
items[].totalOwnerNetAfterDiscount number Số chủ thực nhận hiển thị list.
items[].closing object? Có nếu đã chốt.

Failed response

400 error 
{
  "type": "/employee/invalid-request",
  "message": "Invalid request"
}

Notes

  • List chỉ hiện ngày có attendance hoặc closing.
  • Range tối đa 31 ngày.

POST/api/v1/employee/session/close

Owner xác nhận chốt sổ ngày.

Auth: Backend access tokenScope: owner + branch accessUsed by: Settlement confirm

Headers

Field Type Required Rule Example
Authorization string Yes Bearer accessToken sau signin/refresh-token. Bearer eyJ...
X-Firebase-AppCheck string Prod Firebase App Check token. Monitoring không cần. eyJ...
Content-Type string Yes application/json. application/json
X-Idempotency-Key string Recommended Key ổn định cho POST/PATCH/DELETE để tránh ghi trùng. attendance-2026-06-06-001

Query params

Không có query params.

Request body

Field Type Required Rule Example
branchId/storeId string Yes Branch id. branch_123
workDate/date date Yes YYYY-MM-DD. 2026-06-06
ownerDiscountCoverageRate number No 0|50|100, default 50. 50
closedAt number No Unix ms timestamp. 1780000000000
request.json 
{
  "branchId": "branch_123",
  "workDate": "2026-06-06",
  "ownerDiscountCoverageRate": 50
}

cURL

curl 
curl -X POST "$API_BASE/employee/session/close" \
  -H "Authorization: Bearer eyJ..." \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN" \
  -H "Content-Type: application/json" \
  -H "X-Idempotency-Key: attendance-2026-06-06-001" \
  -d '{"branchId":"branch_123","workDate":"2026-06-06","ownerDiscountCoverageRate":50}'

Successful response

200 response

  "workDate": "2026-06-06",

  "storeId": "branch_123",
  "ownerDiscountCoverageRate": 50,
  "discountAllocationMethod": "revenue_share",
  "employeeSummaries": [
    {
      "employeeUserId": "emp_1",
      "employeeName": "Hải",
      "compensationModel": "commission",
      "totalRevenue": 45,
      "discountAllocated": 2,
      "ownerDiscountSupported": 0,
      "employeeEarning": 32
    }
  ],
  "summary": {
    "totalEntries": 2,
    "subtotalAmount": 105,
    "totalDiscountAmount": 5,
    "totalEmployeeDiscountAmount": 2,
    "totalOwnerDiscountAmount": 3,
    "totalNetAmount": 100,
    "totalOwnerCommission": 68,
    "totalEmployeeEarning": 32
  }
}

Response fields

Field Type Meaning
id string Closing id.
discountAllocationMethod revenue_share Method lưu vào closing.
summary.totalOwnerDiscountAmount number Tổng chủ chịu discount.

Failed response

409 error 
{
  "type": "/employee/invalid-settlement-state",
  "message": "The selected branch work day is not ready to be settled"
}

Notes

  • Chỉ close khi có attendance, tất cả closed, không incomplete.
  • Ngày all-fixed vẫn close được; fixed share chuyển chủ chịu.
