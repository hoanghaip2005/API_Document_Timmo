POST/api/v1/auth/signin

Đổi Firebase ID token của user hiện tại thành backend session.

Auth: Firebase ID tokenScope: owner|employee; admin dùng endpoint riêngUsed by: Sign-in guard

Headers

Field Type Required Rule Example
Authorization string Yes Bearer Firebase ID token, không phải backend accessToken. Bearer eyJfirebase...
X-Firebase-AppCheck string Prod Firebase App Check token. eyJ...

Query params

Không có query params.

Request body

Không có body.

cURL

curl 
curl -X POST "$API_BASE/auth/signin" \
  -H "Authorization: Bearer eyJfirebase..." \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN"

Successful response

201 response 
{
  "accessToken": "Bearer eyJ...",
  "refreshToken": "Bearer eyJ...",
  "tokenType": "Bearer",
  "sessionId": "session_123",
  "accessTokenExpiresAt": 1780000000000,
  "user": {
    "uid": "user_123",
    "email": "owner@example.com",
    "shopId": "shop_123",
    "role": "owner",
    "name": "Owner"
  },
  "scope": {
    "shopId": "shop_123"
  }
}

Response fields

Field Type Meaning
accessToken string Token dùng cho business API.
refreshToken string Token cấp accessToken mới.
user.role owner|employee Role private app.
scope.shopId string Shop scope.
scope.branchId string? Có với employee.

Failed response

403 error 
{
  "type": "/auth/branch-not-configured",
  "message": "Branch-scoped account is missing branch configuration"
}

Notes

  • Body không bắt buộc; uid lấy từ Firebase token.
  • Employee phải có branchId active.
POST/api/v1/auth/refresh-token

Cấp access token mới từ refreshToken.

Auth: Refresh token bodyScope: Session hiện tạiUsed by: authorizedApiRequest/session refresh

Headers

Field Type Required Rule Example
Content-Type string Yes application/json. application/json
X-Firebase-AppCheck Prod Prod Firebase App Check token nếu production bật App Check. eyJ...

Query params

Không có query params.

Request body

Field Type Required Rule Example
refreshToken string Yes Có hoặc không có prefix Bearer. Bearer eyJ...
request.json 
{
  "refreshToken": "Bearer eyJ..."
}

cURL

curl 
curl -X POST "$API_BASE/auth/refresh-token" \
  -H "Content-Type: application/json" \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN" \
  -d '{"refreshToken":"Bearer eyJ..."}'

Successful response

200 response 
{
  "accessToken": "Bearer eyJ...",
  "refreshToken": "Bearer eyJ...",
  "tokenType": "Bearer",
  "sessionId": "session_123",
  "accessTokenExpiresAt": 1780000000000,
  "scope": {
    "shopId": "shop_123"
  }
}

Response fields

Field Type Meaning
accessToken string Access token mới.
refreshToken string Refresh token cũ, giữ prefix Bearer.
permissions string[] Permission theo role.
scope object Shop/branch scope.

Failed response

401 error 
{
  "type": "/auth/refresh-token-expired",
  "message": "Refresh token expired"
}

Notes

  • Nếu token revoked/hết hạn thì logout local.
