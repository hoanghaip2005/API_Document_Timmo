GET/api/v1/notifications

Notification feed cho user hiện tại.

Auth: Backend access tokenScope: owner|employeeUsed by: Notifications pages

Headers

Field Type Required Rule Example
Authorization string Yes Bearer accessToken sau signin/refresh-token. Bearer eyJ...
X-Firebase-AppCheck string Prod Firebase App Check token. Monitoring không cần. eyJ...

Query params

Không có query params.

Request body

GET không có body.

cURL

curl 
curl -X GET "$API_BASE/notifications" \
  -H "Authorization: Bearer eyJ..." \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN"

Successful response

200 response 
{
  "items": [
    {
      "id": "noti_1",
      "type": "correction_request",
      "title": "Yêu cầu sửa chấm công",
      "read": false,
      "createdAt": 1780000000000
    }
  ]
}

Response fields

Field Type Meaning
items[] Notification[] Feed notifications.

Failed response

401 error 
{
  "type": "/auth/invalid-token",
  "message": "Invalid authorization token"
}

Notes

  • Read-only feed hiện tại.
GET/api/v1/monitoring/health

Liveness probe.

Auth: NoneScope: Public infraUsed by: Cloud Run health

Headers

Không cần header đặc biệt.

Query params

Không có query params.

Request body

GET không có body.

cURL

curl 
curl -X GET "$API_BASE/monitoring/health"

Successful response

200 response 
{
  "status": "ok",
  "service": "nail-salon-backend"
}

Response fields

Field Type Meaning
status string ok nếu process live.

Failed response

500 error 
{
  "type": "/internal-server-error",
  "message": "Internal Server Error"
}

Notes

  • Mounted trước AppCheck.
