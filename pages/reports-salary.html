GET/api/v1/employee/report/owner-summary

Owner report optimized.

Auth: Backend access tokenScope: owner + branch accessUsed by: /reports

Headers

Field Type Required Rule Example
Authorization string Yes Bearer accessToken sau signin/refresh-token. Bearer eyJ...
X-Firebase-AppCheck string Prod Firebase App Check token. Monitoring không cần. eyJ...

Query params

Field Type Required Rule Example
branchId string Yes Branch id. branch_123
startDate/fromWorkDate date Yes Start date. 2026-06-01
endDate/toWorkDate date Yes End date, max 31 ngày. 2026-06-30
groupBy enum No day|month. day

Request body

GET không có body.

cURL

curl 
curl -X GET "$API_BASE/employee/report/owner-summary?branchId=branch_123&startDate=2026-06-01&endDate=2026-06-30&groupBy=day" \
  -H "Authorization: Bearer eyJ..." \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN"

Successful response

200 response 
{
  "summary": {
    "totalRevenue": 680,
    "totalDiscount": 20,
    "totalNetAmount": 660
  },
  "revenueByDate": [
    {
      "date": "2026-06-06",
      "revenue": 105

  ],

    {
      "employeeUserId": "emp_1",
      "name": "Hải",

    }
  ],

    {
      "serviceId": "svc_1",
      "name": "Gel manicure",
      "revenue": 45
    }
  ]
}

Response fields

Field Type Meaning

employees[] object[] Breakdown nhân viên.

{
  "type": "/employee/branch-required",
  "message": "A specific branch must be selected for reports"
}

Notes

  • Optimized dùng weekly-report cho historical data khi có.

POST/api/v1/weekly-report

Generate/persist weekly report.

Auth: Backend access tokenScope: owner + branch accessUsed by: Report precompute/admin

Headers

Field Type Required Rule Example
Authorization string Yes Bearer accessToken sau signin/refresh-token. Bearer eyJ...
X-Firebase-AppCheck string Prod Firebase App Check token. Monitoring không cần. eyJ...
Content-Type string Yes application/json. application/json
X-Idempotency-Key string Recommended Key ổn định cho POST/PATCH/DELETE để tránh ghi trùng. attendance-2026-06-06-001

Query params

Không có query params.

Request body

Field Type Required Rule Example
branchId string Yes Branch id. branch_123
weekStartDate date Yes Phải là thứ Hai. 2026-06-01
request.json 
{
  "branchId": "branch_123",
  "weekStartDate": "2026-06-01"
}

cURL

curl 
curl -X POST "$API_BASE/weekly-report" \
  -H "Authorization: Bearer eyJ..." \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN" \
  -H "Content-Type: application/json" \
  -H "X-Idempotency-Key: attendance-2026-06-06-001" \
  -d '{"branchId":"branch_123","weekStartDate":"2026-06-01"}'

Successful response

200 response 
{
  "id": "wr_1",
  "branchId": "branch_123",
  "weekStartDate": "2026-06-01",
  "weekEndDate": "2026-06-07",
  "summary": {
    "totalRevenue": 680
  }
}

Response fields

Field Type Meaning
id string Weekly report id.
sourceClosingIds string[]? Closing ids dùng để generate.

Failed response

409 error 
{
  "type": "/weekly-report/already-exists",
  "message": "Weekly report already exists for this week"
}

Notes

  • Chỉ owner role manage weekly reports.
