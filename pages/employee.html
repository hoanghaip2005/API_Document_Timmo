POST/api/v1/employee/employees

Tạo employee account.

Auth: Backend access tokenScope: owner + branch accessUsed by: Create employee

Headers

Field Type Required Rule Example
Authorization string Yes Bearer accessToken sau signin/refresh-token. Bearer eyJ...
X-Firebase-AppCheck string Prod Firebase App Check token. Monitoring không cần. eyJ...
Content-Type string Yes application/json. application/json
X-Idempotency-Key string Recommended Key ổn định cho POST/PATCH/DELETE để tránh ghi trùng. attendance-2026-06-06-001

Query params

Không có query params.

Request body

Field Type Required Rule Example
email email Yes Email. hai@example.com
password string Yes 8..50; chỉ kiểm tra độ dài. secret123
name string Yes 2..100. Hải
branchId string Yes Branch assignment. branch_123
role enum Yes employee. employee
employeeStatus enum No Default active. active
compensationModel/payType enum No commission|hourly hoặc commission|fixed. commission
hourlyRate money No Dùng khi fixed/hourly. 100
request.json 
{
  "email": "hai@example.com",
  "password": "secret123",
  "name": "Hải",
  "branchId": "branch_123",
  "role": "employee",
  "payType": "commission"
}

cURL

curl 
curl -X POST "$API_BASE/employee/employees" \
  -H "Authorization: Bearer eyJ..." \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN" \
  -H "Content-Type: application/json" \
  -H "X-Idempotency-Key: attendance-2026-06-06-001" \
  -d '{"email":"hai@example.com","password":"secret123","name":"Hải","branchId":"branch_123","role":"employee","payType":"commission"}'

{
  "id": "emp_1",
