Account API

Hồ sơ tài khoản, avatar và bảo mật người dùng hiện tại.

Endpoints

GET/api/v1/account/profilePATCH/api/v1/account/profilePOST/api/v1/account/avatar
GET/api/v1/account/profile

Lấy hồ sơ user hiện tại.

Auth: Backend access tokenScope: owner|employeeUsed by: Account/profile/admin info

Headers

Field Type Required Rule Example
Authorization string Yes Bearer accessToken sau signin/refresh-token. Bearer eyJ...
X-Firebase-AppCheck string Prod Firebase App Check token. Monitoring không cần. eyJ...

Query params

Không có query params.

Request body

GET không có body.

cURL

curl 
curl -X GET "$API_BASE/account/profile" \
  -H "Authorization: Bearer eyJ..." \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN"

Successful response

200 response 
{
  "user": {
    "uid": "user_123",
    "email": "user@example.com",
    "shopId": "shop_123",
    "role": "owner",
    "active": true,
    "name": "Owner",
    "displayName": "Owner",
    "phone": "",
    "position": "",
    "avatarUrl": ""
  }
}

Response fields

Field Type Meaning
user.uid string User id.
user.role owner|employee|admin Role.
user.branchId string? Có với employee.
user.avatarUrl string Avatar URL hoặc empty string.

Failed response

403 error 
{
  "type": "/account/user-disabled",
  "message": "user is disabled"
}

Notes

  • Không trả dữ liệu nhạy cảm như password.
PATCH/api/v1/account/profile

Cập nhật hồ sơ user hiện tại.

Auth: Backend access tokenScope: owner|employeeUsed by: Edit profile

Headers

Field Type Required Rule Example
Authorization string Yes Bearer accessToken sau signin/refresh-token. Bearer eyJ...
X-Firebase-AppCheck string Prod Firebase App Check token. Monitoring không cần. eyJ...
Content-Type string Yes application/json. application/json
X-Idempotency-Key string Recommended Key ổn định cho POST/PATCH/DELETE để tránh ghi trùng. attendance-2026-06-06-001

Query params

Không có query params.

Request body

Field Type Required Rule Example
name/displayName string No 1..100 ký tự. Owner
phone/position/address string No Trimmed string. 090...
gender enum No male|female|other. female
avatarUrl string No URL hoặc empty string. https://...
request.json 
{
  "name": "Owner",
  "phone": "0900000000",
  "avatarUrl": ""
}

cURL

curl 
curl -X PATCH "$API_BASE/account/profile" \
  -H "Authorization: Bearer eyJ..." \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN" \
  -H "Content-Type: application/json" \
  -H "X-Idempotency-Key: attendance-2026-06-06-001" \
  -d '{"name":"Owner","phone":"0900000000","avatarUrl":""}'

Successful response

200 response 
{
  "user": {
    "uid": "user_123",
    "email": "user@example.com",
    "shopId": "shop_123",
    "role": "owner",
    "name": "Owner",
    "phone": "0900000000",
    "avatarUrl": ""
  }
}

Response fields

Field Type Meaning
user AccountProfile Hồ sơ sau update.

Failed response

400 error 
{
  "type": "/account/invalid-request",
  "message": "Invalid request"
}

Notes

  • Cần ít nhất một field.
  • Nếu đổi display/avatar backend sync Firebase profile.
POST/api/v1/account/avatar

Upload avatar user.

Auth: Backend access tokenScope: owner|employeeUsed by: Profile avatar

Headers

Field Type Required Rule Example
Authorization string Yes Bearer accessToken sau signin/refresh-token. Bearer eyJ...
X-Firebase-AppCheck string Prod Firebase App Check token. Monitoring không cần. eyJ...
Content-Type string Yes application/json. application/json
X-Idempotency-Key string Recommended Key ổn định cho POST/PATCH/DELETE để tránh ghi trùng. attendance-2026-06-06-001

Query params

Không có query params.

Request body

Field Type Required Rule Example
file/base64/url string Yes Payload upload JSON theo UI hiện tại. data:image/png;base64,...
request.json 
{
  "image": "data:image/png;base64,..."
}

cURL

curl 
curl -X POST "$API_BASE/account/avatar" \
  -H "Authorization: Bearer eyJ..." \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN" \
  -H "Content-Type: application/json" \
  -H "X-Idempotency-Key: attendance-2026-06-06-001" \
  -d '{"image":"data:image/png;base64,..."}'

Successful response

200 response 
{
  "avatarUrl": "https://storage.example/avatar.png"
}

Response fields

Field Type Meaning
avatarUrl string URL dùng PATCH profile.

Failed response

413 error 
{
  "type": "/request/payload-too-large",
  "message": "Request payload is too large"
}

Notes

  • Route dùng JSON parser 8MB.
