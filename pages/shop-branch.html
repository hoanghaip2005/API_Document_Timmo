Shop Branch API

Quản lý chi nhánh/store trong shop owner.

Endpoints

GET/api/v1/shop/branchGET/api/v1/shop/branch/:branchIdPOST/api/v1/shop/branchPATCH/api/v1/shop/branch/:branchId
GET/api/v1/shop/branch

Danh sách branch trong shop.

Auth: Backend access tokenScope: owner shopUsed by: Home store selector, store system

Headers

Field Type Required Rule Example
Authorization string Yes Bearer accessToken sau signin/refresh-token. Bearer eyJ...
X-Firebase-AppCheck string Prod Firebase App Check token. Monitoring không cần. eyJ...

Query params

Không có query params.

Request body

GET không có body.

cURL

curl 
curl -X GET "$API_BASE/shop/branch" \
  -H "Authorization: Bearer eyJ..." \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN"

Successful response

200 response 
{
  "items": [
    {
      "id": "branch_123",
      "shopId": "shop_123",
      "name": "Cửa hàng Bình Thạnh",
      "settlementCutoffTime": "04:00",
      "status": "active",
      "storeId": "branch_123",
      "addressText": "Bình Thạnh, HCM",
      "label": "Cửa hàng Bình Thạnh",
      "value": "branch_123"
    }
  ]
}

Response fields

Field Type Meaning
items[] Branch[] Danh sách branch.
storeId string|number FE compatibility.

Failed response

403 error 
{
  "type": "/shop/forbidden-role",
  "message": "Forbidden: insufficient permissions"
}

Notes

  • Owner thấy toàn bộ branch trong shop.

POST/api/v1/shop/branch

Tạo branch mới.

Auth: Backend access tokenScope: ownerUsed by: Store system create

Headers

Field Type Required Rule Example
Authorization string Yes Bearer accessToken sau signin/refresh-token. Bearer eyJ...
X-Firebase-AppCheck string Prod Firebase App Check token. Monitoring không cần. eyJ...
Content-Type string Yes application/json. application/json
X-Idempotency-Key string Recommended Key ổn định cho POST/PATCH/DELETE để tránh ghi trùng. attendance-2026-06-06-001

Query params

Không có query params.

Request body

Field Type Required Rule Example
name string Yes 1..100 ký tự. Cửa hàng Bình Thạnh
code string No Max 30. BT01
phone/email/manager string No Thông tin liên hệ. 090...
openTime/closeTime string No Giờ hiển thị. 09:00
settlementCutoffTime HH:mm No Cutoff work day. 04:00
address object No line1/city/state/zipCode/country. {}
status enum No Default active. active
request.json 
{
  "name": "Cửa hàng Bình Thạnh",
  "code": "BT01",
  "settlementCutoffTime": "04:00",
  "status": "active"
}

cURL

curl 
curl -X POST "$API_BASE/shop/branch" \
  -H "Authorization: Bearer eyJ..." \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN" \
  -H "Content-Type: application/json" \
  -H "X-Idempotency-Key: attendance-2026-06-06-001" \
  -d '{"name":"Cửa hàng Bình Thạnh","code":"BT01","settlementCutoffTime":"04:00","status":"active"}'

Successful response

201 response 
{
  "id": "branch_123",
  "shopId": "shop_123",
  "name": "Cửa hàng Bình Thạnh",
  "settlementCutoffTime": "04:00",
  "status": "active",
  "storeId": "branch_123",
  "addressText": "Bình Thạnh, HCM",
  "label": "Cửa hàng Bình Thạnh",
  "value": "branch_123"
}

Response fields

Field Type Meaning
id string Branch id mới.
status string active/pending...

Failed response

400 error 
{
  "type": "/shop/invalid-request",
  "message": "Invalid request"
}

Notes

  • settlementCutoffTime sai format sẽ bị 400.
PATCH/api/v1/shop/branch/:branchId

Cập nhật branch.

Auth: Backend access tokenScope: owner + branch accessUsed by: Store detail/edit

Headers

Field Type Required Rule Example
Authorization string Yes Bearer accessToken sau signin/refresh-token. Bearer eyJ...
X-Firebase-AppCheck string Prod Firebase App Check token. Monitoring không cần. eyJ...
Content-Type string Yes application/json. application/json
X-Idempotency-Key string Recommended Key ổn định cho POST/PATCH/DELETE để tránh ghi trùng. attendance-2026-06-06-001

Query params

Không có query params.

Request body

Field Type Required Rule Example
name/code/phone/email string No Partial update. BT01
settlementCutoffTime HH:mm No HH:mm. 04:00
status enum No Branch status. active
request.json 
{
  "name": "Cửa hàng Bình Thạnh",
  "settlementCutoffTime": "04:00"
}

cURL

curl 
curl -X PATCH "$API_BASE/shop/branch/:branchId" \
  -H "Authorization: Bearer eyJ..." \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN" \
  -H "Content-Type: application/json" \
  -H "X-Idempotency-Key: attendance-2026-06-06-001" \
  -d '{"name":"Cửa hàng Bình Thạnh","settlementCutoffTime":"04:00"}'

Successful response

200 response 
{
  "id": "branch_123",
  "shopId": "shop_123",
  "name": "Cửa hàng Bình Thạnh",
  "settlementCutoffTime": "04:00",
  "status": "active",
  "storeId": "branch_123",
  "addressText": "Bình Thạnh, HCM",
  "label": "Cửa hàng Bình Thạnh",
  "value": "branch_123"
}

Response fields

Field Type Meaning
id string Branch id.

Failed response

400 error 
{
  "type": "/shop/invalid-request",
  "message": "Invalid request"
}

Notes

  • Body phải có ít nhất một field.
