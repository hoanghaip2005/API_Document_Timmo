GET/api/v1/shop/service/bootstrap

Bootstrap dữ liệu cho màn dịch vụ.

Auth: Backend access tokenScope: ownerUsed by: Services/add-service/search

Headers

Field Type Required Rule Example
Authorization string Yes Bearer accessToken sau signin/refresh-token. Bearer eyJ...
X-Firebase-AppCheck string Prod Firebase App Check token. Monitoring không cần. eyJ...

Query params

Không có query params.

Request body

GET không có body.

cURL

curl 
curl -X GET "$API_BASE/shop/service/bootstrap" \
  -H "Authorization: Bearer eyJ..." \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN"

{

      "status": "active",
      "storeId": "branch_123",
      "addressText": "Bình Thạnh, HCM",
      "label": "Cửa hàng Bình Thạnh",
      "value": "branch_123"
    }
  ],
  "services": [
    {
      "id": "svc_1",
      "branchId": "branch_123",
      "name": "Gel manicure",
      "price": 45,
      "amount": "45",
      "category": "manicure",
      "groupService": "Gel",
      "durationMin": 60,
      "durationMax": 60,
      "duration": "60",
      "images": []
    }
  ],
  "catalog": {
    "groups": [
      "Gel",
      "Pedicure"

Response fields

Field Type Meaning
branches[] Branch[] Store options.
services[] Service[] Dịch vụ hiện có.
catalog.groups[] string[] Nhóm dịch vụ hiện có.

Failed response

403 error 
{
  "type": "/shop/forbidden-role",
  "message": "Forbidden: insufficient permissions"
}

Notes

  • Dùng endpoint này trước màn tạo service để có dropdown group.

POST/api/v1/shop/service

Tạo service mới, gồm cả tạo nhóm inline qua groupService.

Auth: Backend access tokenScope: owner + branch accessUsed by: Add service

Headers

Field Type Required Rule Example
Authorization string Yes Bearer accessToken sau signin/refresh-token. Bearer eyJ...
X-Firebase-AppCheck string Prod Firebase App Check token. Monitoring không cần. eyJ...
Content-Type string Yes application/json. application/json
X-Idempotency-Key string Recommended Key ổn định cho POST/PATCH/DELETE để tránh ghi trùng. attendance-2026-06-06-001

Query params

Không có query params.

Request body

Field Type Required Rule Example
branchId string Yes Branch id. branch_123
name string Yes 1..100 ký tự. Gel manicure
price/amount money Yes Một trong hai field. 45
category/groupService enum|string Yes Một trong hai field; groupService cho nhóm mới/hiện có. Gel
duration or durationMin+durationMax number|string Yes Positive integer. 60
description string No Max 500. Gel polish
imageUrls/images/image url[]|url No Tối đa 10 URL. https://...
request.json 
{
  "branchId": "branch_123",
  "name": "Gel manicure",
  "groupService": "Gel",
  "price": 45,
  "duration": 60,
  "description": "Gel polish"
}

cURL

curl 
curl -X POST "$API_BASE/shop/service" \
  -H "Authorization: Bearer eyJ..." \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN" \
  -H "Content-Type: application/json" \
  -H "X-Idempotency-Key: attendance-2026-06-06-001" \
  -d '{"branchId":"branch_123","name":"Gel manicure","groupService":"Gel","price":45,"duration":60,"description":"Gel polish"}'

Successful response

201 response 
{
  "id": "svc_1",
  "branchId": "branch_123",
  "name": "Gel manicure",
  "price": 45,
  "amount": "45",
  "category": "manicure",
  "groupService": "Gel",
  "durationMin": 60,
  "durationMax": 60,
  "duration": "60",
  "images": []
}

Response fields

Field Type Meaning
id string Service id.
groupService string Group hiển thị.
category enum Category đã map từ groupService nếu không gửi.

Failed response

400 error 
{
  "type": "/shop/invalid-request",
  "message": "Invalid request"
}

Notes

  • Không cần màn tạo group riêng.
  • Nếu thiếu price/category/duration backend trả 400.
