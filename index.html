Quick start

  1. Signin bằng Firebase ID token qua POST /api/v1/auth/signin.
  2. Lưu accessToken, refreshToken, scope.
  3. Gọi business API với Authorization: Bearer <accessToken>.
  4. Write request thêm X-Idempotency-Key.
