API Documentation

Timmo Backend API v1

Tài liệu private API cho owner, employee, account, shop, service, attendance, settlement và report. Layout viết lại theo kiểu sidebar + endpoint cards giống các trang API docs hiện đại, bám theo source backend hiện tại.

Gọi API

Business API nằm dưới /api/v1. Monitoring được mount trước App Check để Cloud Run probe được gọi độc lập.

Môi trường Base URL Ghi chú
Production https://nail-salon-backend-jqg7kfo5vq-as.a.run.app/api/v1 Cloud Run production.
Development https://nail-salon-backend-dev-jqg7kfo5vq-as.a.run.app/api/v1 Cloud Run dev.
Local http://localhost:8090/api/v1 Theo SERVICE_PORT; dev log hiện tại dùng 8090.
Write request nên gửi X-Idempotency-Key. Backend có idempotency middleware cho POST, PATCH, DELETE.
curl 
curl "$API_BASE/api/v1/account/profile" \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN"

Xác thực

Token Dùng ở đâu Nguồn
Firebase ID token /auth/signin, /auth/change-password Firebase client SDK.
accessToken Business API sau signin Response signin hoặc refresh-token.
refreshToken Cấp access token mới Body của /auth/refresh-token.
X-Firebase-AppCheck Production API Firebase App Check. Monitoring không cần.
Role Scope Ghi chú
owner shopId, mọi branch trong shop Quản lý nhân viên, dịch vụ, settlement, salary/report.
employee shopId + branchId Employee portal, dữ liệu được assign/tạo.
admin Platform Chỉ dùng admin signin/register-owner.

Quy ước dữ liệu

Nhóm Quy ước
Money Backend shop tạo mới dùng currency: "EUR". Field money là number theo money scale backend. UI có thể hiển thị ký hiệu đ.
Ngày công workDate format YYYY-MM-DD. Business day có thể phụ thuộc settlementCutoffTime.
Giờ trong ngày startTime, endTime là số phút trong ngày; endTime > startTime.
Content-Type Write JSON dùng application/json. Avatar/service image dùng JSON parser 8MB.
Cache GET có thể trả ETag, X-Cache, private cache ngắn. Client invalidate cache sau write.

Lỗi & rate limit

Error envelope thống nhất:

Status Ý nghĩa Ví dụ
400 Request sai schema /employee/invalid-request
401 Token sai/hết hạn /auth/invalid-refresh-token
403 Sai role/scope /employee/forbidden-role
404 Không tồn tại /request/not-found
409 Conflict nghiệp vụ /employee/work-day-already-closed
413 Payload quá lớn /request/payload-too-large
429 Vượt rate limit Header Retry-After
error.json 
{
  "type": "/employee/invalid-request",
  "message": "Invalid request"
}
Global API limit hiện tại: 180 requests/phút/IP dưới /api. Auth signin/register và OTP có rate limit riêng.

Settlement

Rule hiện tại: discountAllocationMethod = "revenue_share", default ownerDiscountCoverageRate = 50. Nhân viên hourly/lương cứng không chịu giảm giá; phần của họ chuyển sang chủ chịu.
Bước Công thức
Chủ chịu cơ bản ownerBaseDiscount = totalDiscount * ownerDiscountCoverageRate / 100
Pool nhân viên employeePool = totalDiscount - ownerBaseDiscount
Chia pool employeePool * employee.totalRevenue / totalRevenue theo tổng doanh thu cả ngày.
Commission Ghi discountAllocated, trừ vào employeeEarning.
Hourly/fixed Ghi ownerDiscountSupported, cộng vào chủ chịu.
Tổng chủ chịu totalOwnerDiscount = ownerBaseDiscount + sum(ownerDiscountSupported)
GET/api/v1/employee/session/settlementsowner
Query Rule
branchId hoặc storeId Required.
fromWorkDate, toWorkDate Required; range 1..31 ngày.

Response item: workDate, status (open|ready|closed), attendance, totalRevenue, totalDiscount, totalNetAmount, totalOwnerNetAfterDiscount, optional closing.

GET/api/v1/employee/session/settlement-previewowner
Query Rule

Response trả employees, discountEligibleEmployees, attendances, items, closing, preview, pendingEmployees.

Mẫu tích hợp

Owner chốt sổ

  1. GET /shop/branch hoặc branch từ bootstrap.
  2. GET /employee/session/settlements?branchId=&fromWorkDate=&toWorkDate= để render list.
  3. GET /employee/session/settlement-preview?branchId=&workDate=&ownerDiscountCoverageRate=50 để render detail.
  4. POST /employee/session/close khi tất cả attendance ready.
settlement-list 
curl "$API_BASE/api/v1/employee/session/settlements?branchId=branch_123&fromWorkDate=2026-06-01&toWorkDate=2026-06-30" \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "X-Firebase-AppCheck: $APP_CHECK_TOKEN"

Employee chốt ngày

  1. GET /employee/me/bootstrap để lấy assignment và attendance.
  2. Nhân viên tạo/sửa attendance trong ngày.
  3. POST /employee/me/attendance/close-day một lần cho ngày đó.
  4. Refresh portal cache; card chuyển trạng thái đã đóng.
close-day-curl 
curl -X POST "$API_BASE/api/v1/employee/me/attendance/close-day" \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -H "X-Idempotency-Key: close-day-2026-06-06" \
  -d '{"workDate":"2026-06-06"}'
